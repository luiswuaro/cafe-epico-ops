# Roadmap

## V0.1 — fundación operativa
- arquitectura, auth, RBAC
- Loyverse mirror/sync/webhook inbox
- recetas y SOPs versionados
- checklist dinámica
- ledger y conteo base
- interfaz empleado/admin inicial

## V0.2 — control de inventario
- flujo UI de conteos
- desviaciones y aprobación de ajustes
- mermas
- mínimos, cobertura y alertas
- movimientos derivados de ventas/recetas

## V0.3 — abastecimiento
- compras/proveedores completos
- costos históricos desde compras
- FIFO/lotes/caducidad
- lista automática de compras

## V0.4 — producción y capacitación
- lotes de alimentos
- consumo/output de inventario
- módulos de capacitación
- matriz de competencias y aprobaciones

## V1.0
- dashboard financiero completo
- permisos endurecidos
- auditoría UI
- multiusuario/multisucursal probado
- procesos de reconciliación observables

## Posterior
- café verde
- tueste/batches/merma
- transferencia de tostado a cafetería
- costeo de café tostado
